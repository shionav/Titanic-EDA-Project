# Titanic Exploratory Data Analysis (EDA) Project

## Project Overview

This project performs Exploratory Data Analysis (EDA) on the Titanic dataset. The purpose of this analysis is to explore factors associated with passenger survival.

## Dataset

The dataset used in this project is the Titanic dataset from Kaggle. It contains information about passengers, including their gender, age, passenger class, fare, and survival status.

## Hypotheses

### Hypothesis 1: Passenger Class and Survival

Passenger survival is associated with passenger class.

### Hypothesis 2: Gender and Survival

Passenger survival is associated with gender.

### Hypothesis 3: Age and Survival

Passenger survival is associated with age.

## Key Findings

The analysis explores the relationship between survival and:

- Passenger class
- Gender
- Age

The results and visualizations are available in the Jupyter Notebook.
